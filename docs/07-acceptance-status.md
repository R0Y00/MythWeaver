## v0.5 玩家 Agent 增量

平台定位明确为 Agent 主导：管理端自然语言配置，玩家端在授权范围内参与。新增玩家字段与归属隔离、可开放交互、私聊绑定与投递、独立模型任务、管理台玩家试运行、状态校验和回执幂等。121 项测试通过，前端构建通过；详情见 [玩家 Agent](09-player-agent.md)。

A01/A09/A10 仍为部分完成：新增私聊与玩家级隔离的自动化测试，但真实模型和 QQ 私聊未验收；角色授权、复杂玩法模块与原始背包导入仍缺失。旧表为此前版本记录，新增结果不表示 M2 完成。


## v0.6 动态模块增量

将验收重心修正为“Agent 可以创建原本不存在的功能”，具体玩法均为按需配置/创建内容，不是固定开发清单。新增 module.put/state/remove、自定义函数与compute效果、运行时语法发现、模块源定义检查，以及算法更新和恢复验证。范围与局限见 [运行时模块](10-runtime-modules.md)，不能等同任意代码插件系统。

验证记录：完整回归135项通过，另2项新增保护用例通过；模块专项共16项通过。前端构建与本机v0.6 HTTP读取检查通过。仍不能将此声明为任意代码扩展或完整M2验收完成。
